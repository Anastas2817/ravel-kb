# ADR-001: Раздельные счётчики id и хранение «индекс = id»

**Статус:** принят (неделя 1).

**Контекст.** Модели нужны стабильные идентификаторы узлов и рёбер: на них ссылаются связи, позиции, сериализация и будущий undo/redo. Варианты: глобальный счётчик, раздельные счётчики по видам сущностей, GUID.

**Решение.** Раздельные счётчики `next_id_node` / `next_id_relation`; узлы и рёбра хранятся в `std::vector` со слотом `индекс = id − 1`; удалённые слоты — фиктивными объектами (id 0). Счётчики сериализуются в файл и восстанавливаются как есть, а не вычисляются по максимуму.

**Отклонённые альтернативы.** Глобальный счётчик (смешение видов, лишняя ширина типа не нужна); GUID (нечитаемо в отладке и ручном diff файлов, избыточен для однофайловой модели).

**Следствия.** O(1) доступ к сущности по id; «дырки» после удалений не сжимаются (неэкономность принята, компактный формат — в перспективах); `Graph::FromSnapshot` обязана восстанавливать слоты и валидировать счётчики (инвариант 1).
