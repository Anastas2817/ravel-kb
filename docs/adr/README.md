# ADR — архитектурные решения

Здесь фиксируются значимые архитектурные решения (Architecture Decision Records): контекст, принятое решение, отклонённые альтернативы, следствия. Формат одного ADR — короткий документ с заголовками: **Статус · Контекст · Решение · Отклонённые альтернативы · Следствия**.

Правила:

- Нумерация сквозная (`ADR-NNN-kebab-case-title.md`), статус один из: *принят · отклонён · заменён ADR-NNN*.
- Решение здесь — выжимка; полное обоснование живёт в [implementation.md](../implementation.md) (правила R*) и [architecture.md](../architecture.md). ADR не дублирует их, а ссылается.
- «Принято без обсуждения» — тоже запись: мелкие решения дешевле откатить, когда видно, когда и почему они появились.
