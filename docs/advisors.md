# Легенда света (advisors)

Статус: проектный документ (2026-10-21; перенесён в репозиторий 2026-10-22).
Слой advisors — представительский слой принципа «система предлагает —
пользователь решает» (spec §1). В 12-недельный MVP целиком не входит;
приоритеты — раздел 6.

## 0. Принцип

Достаточно автоматики, чтобы сосредоточиться на понимании, и не достаточно,
чтобы его ухудшить. Ручная структура — философски правильная, но дорогая;
Ravel делает её достаточно дешёвой, чтобы её реально строили, и при этом
не отдаёт автоматике ни одного решения. Раскладка — слой отображения
онтологии, не продукт. Совет — вопрос, не вердикт и не alarm.

## 1. Грамматика

1. **Один материал — свет** (свечение, тень, проблеск, затмение). Грамматика —
   жесты, не объекты: у каждого совета свой жест, а не отдельный виджет.
2. **Совет — вопрос.** Никаких красных бейджей, «CYCLE DETECTED». Приглашает
   посмотреть, не указывает на ошибку.
3. **Клик подсвечивает, не действует.** Выделяет элементы жеста (рёбра цикла);
   действия — только ручные (drag, смена типа, перемещение).
4. **Жизненный цикл:** активный жест (2–4 итерации или 5 сек) → покой (пульс/
   свечение) → признание (гаснет; живёт в статус-баре, клик по которому
   перевыпускает совет).
5. **Бюджет движения:** ≤2 подвижных совета одновременно; новые рождаются
   сразу в покое.
6. **Бюджет статичных слоёв:** приоритетная очередь световых слоёв — при
   конфликте видимы высокоприоритетные, остальные скрыты; на один узел —
   не более двух эффектов одновременно (читаемость важнее полноты, spec §1).
7. **Не перекрывать содержимое:** советы под текстом узлов, титулы не закрывать;
   обязательна статичная альтернатива (reduced motion).
8. **Считываемость без легенды** (тест «висячей верёвочки» PARC): свет =
   «здесь интересно», тяжесть = «много связей», темнота = «ещё не осмыслено»,
   мерцание = «ещё не решено». Не проходит тест — жест переделывается или
   отбрасывается.

## 2. Оси параметров

| Параметр | Ось смысла |
| --- | --- |
| Яркость/непрозрачность | уверенность («интересность») |
| Температура (тёплый↔холодный) | открытая ось; кандидат заполнения — происхождение/авторство (созвездие источника, §3); свежесть правок уже занята стадиями свечения |
| Скорость изменения | мимолётность ↔ долгожительство (ритм) |
| Геометрия (тень, размер) | степень, натяжение |

**Ритм (темп как семантика):** ничто долгоживущее не меняется быстро, ничто
мимолётное не пульсирует долго. Светлячок (событие) быстр; тень хаба (состояние)
растёт медленно; маяк живёт только в жесте. Жест, нарушающий свой темп, неверен.
Мерцание — флуктуация, не движение: бюджет-дружелюбно.

## 3. Словарь жестов

Единый формат: **Совет** — триггер → активность → покой. Смысл одной строкой.

**Светлячок (цикл).** Ребро завершило цикл.
Активность: светлячок летит по петле 2–4 прохода, глаз прослеживает A→B→C→A.
Покой: едва заметный пульс на рёбрах цикла.
Смысл: «здесь цикл: создать связь или сменить тип?» Клик подсвечивает рёбра,
совет гаснет. Цикл — вопрос о глубине или об ошибке (перекрёстные связи, spec §2.1).

**Тень хаба.** Степень узла > N.
Активность: тень мягко растёт пропорционально степени.
Покой: размытая тень ограниченного размера (cap), без анимации; исчезает при
снижении степени.
Смысл: «этот узел сложно видеть из-за хаба» — окклюзия читаемости, не наказание.
Светлая тень вверх (много исходящих, тяга к общему), тёмная вниз (много входящих,
утяжеление деталями) — подтвердить тестом без легенды, иначе одна тень.
Не путать с затмением: тень хаба — маленькая тень под самим узлом, затмение —
его тень на соседях.

**Хрупкая связь.** Обратное ребро у типа с флагом `antisymmetric`.
Активность: мерцание — пульс рассыпающегося штриха.
Покой: слабый неровный пульс ребра. Гаснет при устранении нарушения.
Смысл: «связь хрупкая». Регистр вопроса, не alarm.

**Маяк (link prediction).** Жест создания связи из узла.
Активность: мягкая подсветка кандидатов, усиливается к лучшему рангу;
живёт только во время жеста, отпускание кнопки — всё гаснет.
Покой: нет (событие в жесте; светлячок выпускается по клику из счётчика, не сам).
Смысл: «вот куда можно». Пенумбра неуверенности: градация непрозрачности
вместо порога «подсветить/нет» — градации приглашают размышление.

**Зеркало (призрачная иерархия, persp. §2).** Переключение доминирующего типа связи.
Активность: отражение узла в позиции альтернативной раскладки.
Покой: режим постоянен, пока выбран вид; возврат к исходному.
Смысл: одно небо, разные фигуры — сезонность. Звёзды (узлы) остаются,
меняются только линии: аргумент за view-зависимые позиции (per-view §2).

**Натяжение позиции.** Ручная позиция далеко от раскладочной.
Активность: отсвет (afterglow) при перемещении.
Покой: слабое свечение узла; по запросу «показать натяжение» — тонкая стрелка
к раскладочной позиции.
Смысл: «позиция ручная». Натяжение считается по последнему стабильному снимку
фона, не по каждому кадру (открытый вопрос 5).

**Освещённость области (режим-линза).** Aggregate view.
Активность: плотные связные зоны подсвечены, листья (степень 1) затемнены —
«непросвещённость».
Покой: режим по тоглу, не постоянный; выключение — возврат.
Смысл: режим-линза поверх DOI-функции (Furnas, fisheye 1986): выделенное —
в полном свете, остальное растворяется по мере «интереса». Не фильтр поверх
карты, а вид; раскладка Сугиямы не ломается (топологическая линза Gansner–
Koren–North — комбинаторное упрощение, не геометрический зум).

**Стадия свечения (восход → полдень → сумерки).** Свежесть правок.
Активность/покой: статичный параметр температуры, без анимации; дрейф фокуса
двигает «дымку» без единого движущегося элемента (дружит с reduced motion).
Смысл: недавно редактированное светится тёплым «утром», забытое уходит
в «сумерки». Температура внимания, не ошибка. Формализует центр↔периферию
(Weiser & Brown) статичным параметром.

**Мерцание свечи.** Нестабильность / вероятностные кандидаты.
Активность: неровный, «задыхающийся» свет.
Покой: флуктуация (не движение, не пульс-цикл).
Смысл: неустойчивое пламя — открытый диалог, незавершённый жест; вероятностные
кандидаты мерцают, детерминированные факты горят ровно. Мерцание = «ещё не
решено» ≠ alarm.

**Затмение (умбра).** Перегруженный хаб закрывает соседей.
Активность/покой: тень, отбрасываемая хабом на соседей, — состояние: живёт,
пока жив перегруз, без пульса-цикла.
Смысл: читается как «мешает видеть», не как «плохой узел». В паре с тенью хаба:
затмение — окклюзия соседей, тень — окклюзия самого хаба. Не путать с лунным
затмением инкубатора (ниже): то — тень масштаба всей карты, не локальная.

**Гало предков.** Транзитивные типы (spec §5.3).
Активность/покой: ореол вокруг источника света, толщина = число выводимых
предков (транзитивная ширина).
Смысл: «от этого исходит много».

**«Тебя ждут» (световое просачивание).** Мнимый узел ссылается на настоящий.
Активность/покой: едва заметный тёплый ореол на реальном узле.
Смысл: единственный свет мнимых, разрешённый на карте. Свет из-за двери
инкубатора лежит на *настоящем* узле. Клик поднимает черновик в панели
инкубатора, не материализует его (правило 3). Дом — инкубатор (persp. §9).

**Свет за горизонтом.** Узел-источник совета за пределами экрана.
Активность: мягкий светлый блик на краю вьюпорта в направлении узла.
Смысл: off-screen-визуализация (стандарт в играх). Совет не молчит, даже если
цикл полностью за экраном.

**Восход и закат (переход между измерениями, persp. §9).** Материализация /
уход мнимого узла.
Активность: тёплый полупрозрачный рассвет на пару секунд, затем зажигание
на раскладочной позиции снизу (частное — снизу, spec §5.1). Симметрично закат:
узел уходит за горизонт обратно на луну.
Смысл: переход между измерениями, не появление из ниоткуда. Undo/redo —
та же анимация в обратную сторону + световое эхо.

**Луна инкубатора (очередь черновиков).** Панель инкубатора = мини-небо,
не список: та же карта ночью, звёзды одной величины, без степеней и метрик.
Активность: **лунное затмение** — мнимых больше, чем настоящих: огромная тень,
отбрасываемая «луной» на всю карту, — редкое событие один раз, без пульса-цикла;
заставляет спросить «что с луной?» и посмотреть на очередь. (Отличие от
затмения хаба — масштаб: там локальная тень узла на соседях.) Импорт партии
черновиков — **метеорный поток**: видимое событие, ничего не решает, «сырьё
доставлено».
Покой: освещённость диска = заполненность очереди относительно настоящих узлов;
полнолуние = очередь сравнялась с картой.
Смысл: informative thing без вердиктального счётчика. Кандидаты типов внутри
инкубатора — синхронное мерцание (те же звёзды, другая фаза). Клик по луне
только показывает панель. Материализация = запуск восхода одним ручным жестом.

**Полярная (узел-якорь).** Пользовательская метка «это моя опора, отсюда думаю».
Активность/покой: ровный, непульсирующий свет — единственный свет на карте,
который не дышит.
Смысл: не совет, а навигационный инструмент (как Полярная у моряков: не самая
яркая, но единственная неподвижная). Три ритма света: дышит / мерцает / горит
ровно.

**Линза времени (второй режим-линза).** Opt-in, default off (как звук),
подавляется во время жеста.
Активность: **световой след** — рёбра, участвовавшие в создании и правках узла,
загораются последовательно, в порядке летописи; **созвездие сессии** — узлы,
тронутые за сеанс, соединяются тонкими световыми линиями (пунктир, слабее
рёбер) в порядке времени.
Покой: не переживает загрузку — память сессии тает, структура остаётся (slow tech).
Смысл: карта показывает *что* ты думаешь, след — *как* ты думал. Не advisor,
в таблицу жестов §3 не идёт; дом — рядом с освещённостью как второй режим-линзы.

**Созвездие источника (линза происхождения, третий режим-линза).** У узлов
появляется поле источника (persp. §17: книга, лекция, разговор — что навело
на мысль).
Активность: выбранный источник разом вспыхивает на всех «своих» узлах единым
тёплым оттенком; поверх карты проступает созвездие. Клик подсвечивает его
узлы, не действует (правило 3).
Покой: едва заметное тёплое свечение на «своих» узлах; остальная карта
слегка холодеет.
Смысл: «эти мысли пришли из одного колодца» — и качество переработки: один
источник → одно плотное созвездие из 30 узлов = декомпозиция случилась; один
источник → три разрозненных огонька = книга «не дошла». Картина созвездия —
визуальный ответ на «что я сейчас узнал?», диагностика принципа «пиши
своими словами». Не путать с созвездием сессии (линза времени): то — *как*
думал, это — *откуда* взял.
Автоматика (не MVP; форма link prediction, research §5): два узла разных
источников сходятся в одном утверждении (похожие description на сходных
рёбрах) — мерцание свечи «ещё не решено, чьё это».

## 4. Мета-принципы

- **Одно солнце.** Вся графика — один источник света сверху: кинематографичный
  мотивированный свет + вертикальная семантика spec §5.1 (общее сверху
  освещает частное). Направление тени — часть грамматики, не декор.
- **Воздушная перспектива расстояния.** Чем дальше от текущего фокуса (курсор,
  последний отредактированный), тем светлее-холоднее-бестелеснее узел. Не
  важность, а удалённость от текущей мысли. Переходы температуры, не скольжения.
- **Центр ↔ периферия (calm technology).** Интерфейс учитывает внимание, не
  требует его (attentive UI): активация советов по контексту внимания.
- **Созвездия (semantic zoom).** При отдалении карта переходит в «ночной режим»:
  узлы — звёзды, рёбра — созвездия. Дёшево в QGraphicsScene (LOD по масштабу);
  помогает при 10²–10³ узлах.
- **Синхронная фаза.** Кандидаты link prediction мерцают в одной фазе — звёзды
  одного созвездия «знают друг о друге» синхронностью, не яркостью (ось
  уверенности) и не температурой (ось свежести).
- **Световое эхо = soft-delete (ADR-002).** Удалённое ребро остывает секунду-две,
  не исчезает мгновенно; undo — повторное зажигание. Честное отражение семантики
  модели (мёртвые данные физически ещё лежат в `nodes_`/`relations_`), а не её
  длительности: трупы в модели живут до границы сессии, эхо — секунды.
  Анабиоз = свет ещё долетает.
- **Космология.** Небо — автоматика (раскладка), звёзды — ручное (связи).
  Созвездие — не объект мира, а мысль, натянутая на мир. Тёмная материя:
  подуманное, но не сказанное имеет массу — мнимые узлы уже притягивают
  настоящие (просачивание) и искажают луну (очередь).
- **Уведомления (треугольник McCrickard).** Проверка жеста: светлячок = высокое
  comprehension, среднее прерывание; тень = низкое прерывание и reaction;
  маяк = высокая reaction (жест!), низкое прерывание. Жест с «высоким по всем
  трём» — alarm, в словарь не проходит.
- **Инвалидация по undo.** Совет на отменённом действии гаснет немедленно
  (по undo, не по таймеру).

## 5. Границы (чтобы не размыть главное свойство)

- Никакого света мнимых на карте, кроме просачивания («тебя ждут»). Черновик,
  мерцающий на карте, — уже на карте; инкубатор схлопнулся бы в ещё один тип узла.
- Затмение — состояние, не событие: тень хаба на соседях живёт, пока жив
  перегруз; без пульса-цикла. (Лунное затмение — наоборот, событие: один раз.)
- Луна и советы не действуют: клик только показывает/подсвечивает (правило 3).
- В инкубаторе нет метрик и размеров — иначе очередь станет самонаблюдением
  (вердикт, против правила 2).
- Линза времени не оценивает: слепые зоны сознательно не показываем
  («мало провёл времени» — телеметрия, запрещена).

## 6. Приоритеты

- **Post-MVP1:** светлячок цикла; тени хабов; хрупкая связь (+ флаг `antisymmetric`).
- **Post-MVP2:** маяк link prediction; зеркало призрачных иерархий (per-view §2);
  освещённость области; созвездие источника (линза происхождения, §3).
- **Исследовательский уровень:** линза времени (световой след, созвездие сессии).

## 7. Открытые вопросы (закрыть до реализации)

1. Светлая/тёмная тень хабов: семантику подтвердить ручным тестом без легенды;
   если различие не считывается — оставить одну тень.
2. Освещённость: только режим-линза или постоянное состояние? Постоянное
   рискует конфликтовать с читаемостью карты.
3. Советы и undo/redo: гашение по undo-инвалидации (см. мета-принципы).
4. Маяк и ранжирование: порог релевантности и максимум подсвеченных узлов,
   чтобы маяк не стал гирляндой.
5. Советы × фоновая раскладка (persp. §6): натяжение по последнему стабильному
   снимку, не по каждому кадру.
6. Производительность эффектов в QGraphicsScene: свечение, тени и размытие —
   самые дорогие примитивы сцены. Стратегия (предрендеренные спрайты, LOD по
   масштабу, OpenGL-viewport) выбирается по замерам на карте 10²–10³ узлов;
   замеряем по мере роста числа жестов, не заранее (правило 1 implementation.md).

## 8. Правки в смежные документы

1. **Spec §5.4 (циклы):** предупреждение «обнаружен цикл A→B→C→A — разорвать
   или пометить допустимым» — вердиктальный тон и действие по клику (правила
   2–3 запрещают). Тон смягчён до совета-вопроса (выполнено 2026-10-22);
   `allowed_cycles` остаётся ручной пометкой, и для помеченных циклов
   светлячок не выпускается: цикл осознан и не требует исправления.
2. **metaphors.md:** граница слоёв метафор добавлена (2026-10-22): космос
   не поползёт в контракты архитектуры без перевода одной фразой (правило 33
   implementation.md).
3. **Статус-бар (спутник — Луна):** носитель признанного совета (клик
   перевыпускает совет).
4. **Per-view позиции (persp. §2):** нужны для зеркала; сезонность — мягкий
   аргумент в пользу view-зависимых состояний фигур при глобальном небе
   (ручные позиции — глобальны, ADR-003).
5. **Поле источника (persp. §17):** перспектива заведена (2026-10-30): поле
   само по себе мёртвое, оживляет его линза «созвездие источника» (§3);
   ось температуры получила кандидата заполнения (§2). Обратное влияние:
   advisors отнесён в persp. §17 как единственный механизм чтения поля.

## 9. Источники

1. Weiser M., Brown J.S. — calm technology. Каноническая ссылка: «The Coming
   Age of Calm Technology» (Xerox PARC, 1996; в исходных заметках фигурировала
   как «Designing Calm Technology», 1995). Отсюда: центр↔периферия,
   informative things и прототип «висячей верёвочки» (Dangling String) —
   верёвочка PARC, кодирующая нагрузку сети.
2. Hallnäs L., Redström J. «Slow Technology — Designing for Reflection» (2001).
   Personal and Ubiquitous Computing, 5(3), 201–212, DOI 10.1007/PL00000019.
   Отсюда: проектирование для размышления, не для эффективности; скорость
   изменения как носитель смысла.
3. Vertegaal R. «Attentive User Interfaces» (2003). Communications of the ACM,
   46(3), 30–33, DOI 10.1145/636772.636794. Отсюда: интерфейс учитывает
   внимание, не требует его; активация по контексту внимания.
4. Furnas G.W. «Generalized Fisheye Views» (1986). CHI '86, pp. 16–23.
   Отсюда: degree-of-interest, focus+context — основа «освещённости области».
5. Gansner E., Koren Y., North S. «Topological Fisheye Views for Visualizing
   Large Graphs» — IEEE Transactions on Visualization and Computer Graphics,
   11(4), 457–468, 2005 (расширенная версия доклада InfoVis 2004; год и
   выходные данные уточнены при записи). Отсюда: топологическая линза, не
   ломающая раскладку.
6. McCrickard D.S., Chewar C.M. «Attuning notification design to user goals
   and attention costs», CACM 46(3), 67–72, 2003 — фреймворк interruption /
   reaction / comprehension (точная ссылка уточнена при записи).
