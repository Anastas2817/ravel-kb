# C4-диаграммы

Две версии диаграмм C1–C4 поддерживаются параллельно:

- **`*.puml` → `*.png` (в корне каталога)** — источник истины по составу компонентов.
  Правится текстом, PNG перегенерируется:
  `tools/jdk-21.0.12.1+1-jre/bin/java -jar tools/plantuml.jar -Playout=smetana -charset UTF-8 -tpng docs/assets/c4/*.puml`
  (по рекомендации преподавателя; см. architecture.md).
- **`pretty/*.png`** — авторская ручная версия (Excalidraw). **Поддерживается параллельно,
  отказа от неё нет** (по состоянию на 2026-10-09): она несёт ту же структуру, но с расстановкой
  акцентов автора. При расхождении с puml-версией актуализирует руками автор; источником
  истины по составу остаются `*.puml`.

PNG в обеих версиях не правятся руками.
