# Метафоры проекта: федерация, конфедерация, мировой порядок

Статус: рабочий документ 2026-10-15. Не нормативен. Назначение: (1) сохранить
метафору, в которой продумана архитектура, чтобы через год было проще вспомнить
«почему так»; (2) показать ход проектирования. Каждый элемент метафоры обязан
переводиться в контракт одной фразой — иначе он эстетика, а эстетика в
репозитории не выживает (см. эмпирическое правило 33 в implementation.md).

## Государственное устройство Ravel

| Метафора | Сущность | Контракт (перевод одной фразой) |
|---|---|---|
| **Федерация** | `core::Graph` | Владеет данными (территория), отвечает и за живых, и за мёртвых жителей (soft-delete, ADR-002), и за процедуру их воскрешения (`Restore*` — правовая процедура без истории). |
| **Перепись населения** | `ForEachLive*` | Единая sanctioned-точка итерации по живым; мутация внутри итерации запрещена. |
| **ЗАГС** | `Relation` / словари типов | Акты гражданского состояния: зарегистрированные связи и их типы, тип существует только полностью заданным («тип отстаивает своё», R8). |
| **Трупы = граждане в анабиозе** | зомби-слоты `nodes_`/`relations_` | Паспорт аннулирован (нет в `access_`), досье хранится на территории федерации (слот не рекультивируется — монотонный рост памяти, осознанная цена суверенитета, ADR-002 §13). |
| **Конфедерация** | `app` | Оперирует только id (паспорта), не хранит досье на жителей федераций. Хранение данных узлов в app — интервенция во внутреннюю политику, от которой смысл конфедерации падает. |
| **Летопись** | undo-стек в app | История — прерогатива конфедерации; Graph знает процедуру воскрешения, но не историю. Симметричное незнание — чистый интерфейс. |
| **Мировой порядок** | `ui` | Инициирует требования (реинкарнация, мутации), не владея ни данными, ни историей. |
| **Суверенитет священен** | — | «Тип отстаивает своё» (R8, R10): конструкторский инвариант, валидация до мутации. |

## Кросс-графовое развитие метафоры (перспектива, см. perspectives §15)

Фрактальная нотация — отражение множества федераций/конфедераций со сферами
влияния (вложенность). Ребро, указывающее в чужой граф, — **посольство**:
запись на своей территории, данные экстерриториальны. Квалифицированный id
(graph + entity) — таможня на границе; раздельные счётчики id (ADR-001) =
суверенные id-пространства, коллизий нет бесплатно. Каскадный undo через границу
двух графов — международный договор о правовой помощи: его нельзя ввести «с
потребителем», он потребует протокола. Знак «(?)» в межграфовой связи —
предмет исследования: inter-ontology typing (два суверена — два словаря).

Финальная ирония (защита): инструмент, чья фича — фрактальные сферы влияния,
сам устроен как конфедерация федераций. Нотация и рантайм совпадают.
